Виконано дві частини за методичкою `4-js.pdf` на основі резюме з лабораторних 2 та 3:

В обох частинах є системна інформація у localStorage та футері, п'ять відгуків із `/posts/5/comments`, модальне вікно через 60000 мс і денна/нічна тема.

## 1. Підключіть свою форму Formspree

**Без особистого endpoint листи не надсилатимуться.** Зараз використано позначку `YOUR_FORM_ID`; вона навмисно блокує відправлення, щоб не показувати помилковий успіх.

1. Відкрийте <https://formspree.io/register>, створіть обліковий запис і підтвердьте свою пошту.
2. Створіть нову форму. Одержувачем у налаштуваннях Formspree вкажіть свою електронну адресу.
3. У розділі **Integration** скопіюйте **Form Endpoint** виду `https://formspree.io/f/xxxxxxxx`.
4. Вставте **одне й те саме посилання** у два місця:
   - `web_lab-4/index.html`: атрибут `action` форми `contact-form`.
   - `lab_2_react/src/config.js`: значення `FORMSPREE_ENDPOINT`.
5. Збережіть файли. Якщо використовуєте зібрану React-версію, повторіть `npm run build`.
6. Надішліть власне тестове повідомлення з кожної частини та перевірте його в Formspree і на своїй пошті. За потреби виконайте запропоноване Formspree підтвердження або CAPTCHA.

Пошта у футері — контактне посилання. Одержувача повідомлень задають саме налаштування Formspree.

Офіційна інструкція: <https://help.formspree.io/articles/building-your-form/building-an-html-form>.

## 2. Запуск частини HTML і JavaScript

1. Розпакуйте архів.
2. Відкрийте папку `web_lab-4` у VS Code.
3. Через розширення **Live Server** натисніть **Open with Live Server** для `index.html`.

Якщо Live Server немає, але встановлений Python, відкрийте термінал у `web_lab-4` і виконайте у Windows:

```powershell
py -m http.server 5500
```

У Linux/macOS команда: `python3 -m http.server 5500`.

Відкрийте <http://localhost:5500>. Для перевірки використовуйте локальний HTTP-сервер, а не відкриття файлу через `file://`.

## 3. Запуск React

Потрібні Node.js **22.12 або новіший** та npm.

У терміналі всередині папки `lab_2_react` виконайте:

```powershell
npm ci
npm run dev
```

Відкрийте адресу, яку виведе Vite, зазвичай <http://localhost:5173>.

Перевірка збірки:

```powershell
npm run build
npm run preview
```

У папці вже є повний React-проєкт. Повторно запускати `npm create vite` не потрібно. `node_modules` і `dist` до архіву не включені; вони створюються відповідними командами.

## 4. Що перевірити і сфотографувати для звіту

1. В обох частинах прокрутіть до **Відгуків**. Мають бути п'ять коментарів для варіанта 5, у порядку сервера. Нічого не сортується.
2. У футері перевірте блок **Інформація у localStorage**. У DevTools → Application → Local Storage виберіть поточну адресу. Ключ `systemInfo` містить JSON із даними браузера та ОС. Футер показує всі наявні ключі цього origin, а не лише `systemInfo`.
3. Натисніть кнопку зміни теми. Зробіть скріншоти денної і нічної тем.
4. Для перевірки таймера відкрийте нову вкладку і нічого не натискайте 60 секунд. Форма має відкритися автоматично.
5. Заповніть Ім'я, Email, Номер телефону та Повідомлення. Після підключення Formspree перевірте доставку тестового листа.
6. Закрийте форму кнопкою **Закрити** або Escape. Вона не відкриється автоматично ще раз у тій самій сесії вкладки, зокрема після перезавантаження. Кнопка **Написати повідомлення** дозволяє відкрити її вручну.
7. Щоб повторити автоматичну появу в тій самій вкладці, видаліть відповідний ключ у DevTools → Application → Session Storage та оновіть сторінку:
   - HTML: `lab4-vanilla-contact-closed`.
   - React: `lab4-react-contact-closed`.

Час визначається за годинником пристрою відвідувача: **07:00 ≤ час < 21:00** — денна тема, решта часу — нічна. Початкова тема залежить від часу; надалі межа день/ніч перевіряється щохвилини. Ручний вибір зберігається до наступного переходу між цими періодами; після перезавантаження тема знову визначається за часом.

Браузер може приховувати точну версію ОС та деякі апаратні параметри. Зберігаються доступні відкриті відомості; код не запитує геолокацію чи доступ до пристроїв. Якщо сховища або інтернет недоступні, сторінка показує повідомлення про відповідну проблему.

У Word-звіті залишено підписані місця для восьми скріншотів сторінок та одного підтвердження доставки. Замініть текст «Місце для скріншота» своїми зображеннями. Фрагменти коду у звіті пояснюють реалізацію, а повні тексти містяться у цьому архіві.
